Star Wars – Fan Web Project

Projeto autoral de Front-end inspirado no universo **Star Wars**, desenvolvido com foco em **design visual, organização de conteúdo e experiência do usuário**.

Este site não é afiliado à Disney ou Lucasfilm.  
Trata-se de um projeto de fã, criado por um fã.

---

Objetivo do Projeto

Demonstrar fundamentos sólidos de desenvolvimento web utilizando:

- HTML semântico
- CSS moderno (layout, transições e microinterações)
- JavaScript aplicado de forma pontual e funcional

O foco principal não é complexidade técnica artificial, mas **clareza visual, consistência e boa experiência de navegação**.

---

O que este projeto demonstra

- Organização de conteúdo em múltiplas seções
- Layout consistente e identidade visual fiel à franquia
- Uso de efeitos de hover e transições suaves
- Grid responsivo para cards e listagens
- Componente de carrossel implementado com JavaScript puro
- Atenção a contraste, tipografia e hierarquia visual

---

Tecnologias Utilizadas

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**

Sem frameworks ou bibliotecas externas.  
A proposta foi explorar ao máximo a base da web.

---
Estrutura do Site

- **Home** – Introdução ao universo Star Wars
- **Sobre a Saga** – Informações e curiosidades
- **Filmes** – Lista cronológica com detalhes
- **Séries** – Separação entre live-action e animação
- **Jogos** – Cards com informações e plataformas
